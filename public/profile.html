What is Intiface Central?

Intiface Central is a free desktop app that acts as a local server between your browser and Bluetooth/USB toys. It must be running before you click “Connect”.

Quick-Start

  1. Download & install from intiface.com/central.
  2. Start the server — press the green Start Server button. Default address: ws://localhost:12345.
  3. Connect here — click Connect, then Scan to find your toy.

Supported toys

Lovense, We-Vibe, Kiiroo, Lelo, Satisfyer, The Handy, and hundreds more — see iostindex.com.
